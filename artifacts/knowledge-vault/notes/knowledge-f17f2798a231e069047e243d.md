## Functional explanation

Status: **documented**

Role: user&#95;windows&#95;preference&#95;settings

This Windows key under the per-user Windows NT&#92;CurrentVersion branch is a documented location for the preference controlling Windows default-printer management. LegacyDefaultPrinterMode determines whether Windows manages the default printer, according to the associated policy state. The broader key name should not be treated as a list of printers or a print-job history. Other values require their own documentation instead of inheriting the default-printer preference’s meaning.

## Atomic claim

Holds the documented user preference for Windows default-printer management.

Scope: **user**

## Meaning in system-level logs

Inspect LegacyDefaultPrinterMode data when interpreting default-printer-management changes here. Collect printer selection or print-service events separately to identify a chosen printer or completed job.

### What the path cannot establish

- The parent path does not identify a default printer or an installed queue.
- A preference write does not prove that a default printer changed or a document was printed.
