## Functional explanation

Status: **documented**

Role: device&#95;setup&#95;class&#95;namespace

Class organizes device setup-class configuration by class GUID. These classes group devices for installation and common configuration. This collection is distinct from the DeviceClasses interface namespace, whose classes describe interfaces exposed to consumers. A record at this level identifies the installation-class area; the actual GUID and setting are still needed before assigning a filter driver, installer or hardware category to the observation.
