## Functional explanation

Status: **documented**

Role: machine&#95;configuration&#95;root

HKEY&#95;LOCAL&#95;MACHINE (HKLM) is the predefined root for configuration associated with the local computer. Its subtrees separate operating-system configuration, software settings, hardware information, and security-related configuration. This layer establishes machine scope; it does not select a particular user profile or identify the operation performed on a descendant key.

## Atomic claim

HKLM identifies configuration associated with the local computer.

Scope: **machine**

## Meaning in system-level logs

An HKLM record establishes machine scope; operation, full child path and value data are still required to identify the affected facility.

### What the path cannot establish

- Machine scope does not identify the process that performed an operation.
- The root does not imply every contained component is enabled.

### Applicability

This describes the documented Windows registry namespace; available descendants and their behavior depend on the installed components and Windows release.
