## Functional explanation

Status: **documented**

Role: active&#95;control&#95;set&#95;filesystem&#95;policies

Policies contains active-control-set policy values used for file-system behavior. The documented FileSys mappings include compression, encryption and deletion-notification settings. These are value-specific policies within a machine namespace, not a single universal enabled state. Interpretation must use the exact value and applicable platform policy contract. Merely seeing Policies in a log does not establish that any of those restrictions is configured or effective.

### Applicability

CSP mappings list specific supported Windows 10 builds with KB5005101 and Windows 11 21H2 onward on listed editions; these delivery requirements are not the creation date of the registry branch.

### Selected values and subkeys

These are documented examples, not an exhaustive schema or observed data.

- **NtfsDisableCompression** (value): Policy value for preventing access to and creation of compressed NTFS files.
- **DisableDeleteNotification** (value): 0 enables deletion notifications; 1 disables them.
