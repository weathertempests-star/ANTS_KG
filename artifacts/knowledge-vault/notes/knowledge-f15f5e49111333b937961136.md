## Functional explanation

Status: **documented**

Role: smb&#95;server&#95;policy

This machine LanmanServer policy key configures the server side of Windows SMB file sharing. Documented settings control cipher-suite preference and negotiation ordering, plus BranchCache generation and version support for content hashes from shared data. The BranchCache settings require the relevant server roles. This policy location is separate from the LanmanServer service configuration branch and does not enumerate current shares or sessions.

## Atomic claim

Stores machine policies for SMB server cipher selection and BranchCache content hashes.

Scope: **machine**

## Meaning in system-level logs

Inspect the value and data, registry operation, and result to distinguish SMB encryption preference from BranchCache configuration. An actual SMB session, negotiated cipher, or generated content hash requires separate operational evidence.

### What the path cannot establish

- The key does not prove the computer exported a share or accepted an SMB connection.
- A configured cipher order does not establish the cipher negotiated in a session.

### Applicability

The referenced ADMX CSP tables list device scope on Pro, Enterprise, Education, and IoT Enterprise: Windows 10 2004/20H2/21H1 with KB5005101, and Windows 11 21H2 or later. These are CSP delivery baselines; they do not date the introduction of the underlying Group Policy setting. BranchCache hash generation requires File Services with File Server and BranchCache for Network Files role services; available SMB ciphers vary by implementation.

### Selected values and subkeys

These are documented examples, not an exhaustive schema or observed data.

- **HonorCipherSuiteOrder** (value): Controls whether the SMB server prefers its own order among mutually supported cipher suites.
