## Functional explanation

Status: **documented**

Role: remote&#95;desktop&#95;administrative&#95;policy

This machine Terminal Services policy key hosts settings for Remote Desktop Services sessions and related client behavior, including resource redirection, authentication requirements, session limits, display encoding, and signed RDP-file use. Despite its historical name, it remains a documented modern policy location. Some policies concern the session host and others the client; the exact value determines the role and cannot be inferred from the parent alone.

## Atomic claim

Stores machine Remote Desktop Services and client policies for session behavior, authentication, redirection, and graphics.

Scope: **machine**

## Meaning in system-level logs

Inspect the exact value and data with operation and result, distinguishing host authentication from client-file or redirection policy. Session existence, accepted logon, clipboard transfer, or remote execution requires session and operational records.

### What the path cannot establish

- The path does not show Remote Desktop is enabled, exposed, or used.
- A configured redirection or authentication policy does not establish a connection, resource transfer, or successful logon.
- The historical Terminal Services and RemoteFX labels do not prove that legacy components are installed.

### Applicability

The referenced ADMX CSP tables list device scope on Pro, Enterprise, Education, and IoT Enterprise: Windows 10 2004/20H2/21H1 with KB5005101, and Windows 11 21H2 or later. These are CSP delivery baselines; they do not date the introduction of the underlying Group Policy setting. Host features depend on supported Windows editions and installed RDS roles; client policies have different roles. The legacy RemoteFX codec setting explicitly concerns RDP 7.1 clients designed for Windows Server 2008 R2 SP1, not all current graphics sessions.

### Selected values and subkeys

These are documented examples, not an exhaustive schema or observed data.

- **AllowSignedFiles** (value): Controls allowing validly signed RDP files and documented default RDP settings in the machine policy variant.
- **UserAuthentication** (value): Controls requiring Network Level Authentication before remote connections to an RD Session Host.
