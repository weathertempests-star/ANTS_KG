## Functional explanation

Status: **documented**

Role: ipv6&#95;parameters

Parameters contains IPv6 settings including the DisabledComponents bitmask. Its name is meaningful because it is under Tcpip6, rather than an arbitrary service. Bitmask data must be decoded to distinguish address preference from disabling selected components. Changes require restart, and even documented disabling configurations retain internal loopback use. A stored value is therefore not a direct observation of all current IPv6 traffic or interface state.

## Atomic claim

Parameters contains IPv6 settings including the DisabledComponents bitmask.

Scope: **machine**

## Meaning in system-level logs

Retain DisabledComponents data as a numeric bitmask and correlate reboot time and interface or connection telemetry.

### What the path cannot establish

- 0x20 expresses IPv4 preference rather than complete IPv6 disablement.
- The value does not fully disable internal loopback IPv6 or mirror the interface checkbox.

### Applicability

The guidance discusses Windows Vista/Server 2008 and later IPv6 behavior and is scoped to supported Windows Server versions.
