## Functional explanation

Status: **structural**

Role: hardware&#95;profile&#95;namespace

Hardware Profiles is the system namespace containing hardware-profile configuration. The Current descendant supplies the path exposed by HKCC. This parent organizes profile-related configuration rather than enumerating every physical device or recording a historical hardware timeline. The exact spaced path is supported by the predefined-key and Plug and Play documentation; current driver guidance treats hardware profiles as deprecated.
