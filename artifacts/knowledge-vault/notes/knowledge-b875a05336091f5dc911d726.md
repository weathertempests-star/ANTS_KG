## Functional explanation

Status: **documented**

Role: file&#95;extension&#95;registration&#95;template

A FileExtension child associates a file-name suffix with a programmatic identifier. The placeholder represents the shape of an extension registration, such as a name beginning with a period, rather than a discovered extension on a host. The association is metadata for resolving a file class. It neither contains a file nor records the opening of one, and downstream interpretation needs the concrete suffix and associated identifier.
