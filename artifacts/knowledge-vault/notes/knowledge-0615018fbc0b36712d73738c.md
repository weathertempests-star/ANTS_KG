## Functional explanation

Status: **documented**

Role: security&#95;event&#95;log&#95;configuration

Security is the service-tree configuration branch for the Security event log. The Security log receives security-audit events such as logon and object-access auditing. The ADMX mapping documents its use for legacy log-access configuration. A reference to this branch therefore concerns security-audit-log settings, not the stored event records. Keep it distinct from the similarly named policy-tree branch and inspect the actual changed data before describing an access-policy change or an effect on log availability.
