## Functional explanation

Status: **structural**

Role: time&#95;provider&#95;policy&#95;namespace

This machine Windows Time TimeProviders namespace groups the policy branches for individual time providers. Its NtpClient descendant controls obtaining time from other servers, while NtpServer controls answering time requests from other computers. The grouping role is inferred from those documented mappings. A provider branch organizes synchronization direction; the parent is not a list of observed time servers or synchronization events.

## Atomic claim

Separates Windows Time policies for receiving and serving NTP time.

Scope: **machine**
