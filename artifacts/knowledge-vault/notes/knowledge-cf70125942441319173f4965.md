## Functional explanation

Status: **documented**

Role: system&#95;control&#95;configuration

Control groups settings that govern system startup and aspects of device configuration within the active control set. Its subkeys organize particular system facilities, including device setup classes and session-manager configuration. This is a configuration namespace, not an instruction to start or stop a service; individual settings must be interpreted under their specific child keys and value names.

## Atomic claim
