## Functional explanation

Status: **structural**

Role: user&#95;internet&#95;security&#95;policy&#95;namespace

This Internet Settings branch organizes user policy configuration for Windows URL security zones. Documented child paths separate ordinary Zones from Lockdown&#95;Zones, with numbered descendants holding individual action policies such as File Explorer OpenSearch query and preview permissions. These are policy locations, distinct from the non-policy Internet Settings preferences. The represented user’s stored settings do not alone determine effective behavior when machine-only security-zone policy or other applicable policy processing governs the consumer.

## Atomic claim

Groups user policy locations for ordinary and locked-down URL security zones.

Scope: **user**

## Meaning in system-level logs

Keep the full zone-branch suffix, user SID, action value, and data in logs. Check applicable machine policy and the consuming feature before treating a user-policy write as an effective security-zone change.

### What the path cannot establish

- This policy branch does not enumerate sites assigned to a zone.
- HKCU policy data alone does not establish effective settings when machine-only policy applies.

### Applicability

This namespace is established by documented Windows security-zone policies. Underlying feature support and policy precedence must be checked on the specific Windows baseline.
