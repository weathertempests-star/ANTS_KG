## Functional explanation

Status: **documented**

Role: setup&#95;event&#95;log&#95;policy

This machine EventLog Setup policy key configures the Setup event log. The reviewed mappings include logging enablement, maximum file size, location, access permissions, retention behavior, and automatic backup. Retention and automatic backup interact when the file becomes full. The key represents administrative controls for the channel; it is not a Windows installation record, an event store, or evidence that setup activity happened.

## Atomic claim

Stores administrative policy for Setup log enablement, capacity, access, retention, and location.

Scope: **machine**

## Meaning in system-level logs

A target here needs the exact value, data, operation, and result to distinguish enablement from file-size or retention changes. Actual setup events or a full-file condition require the channel records or state.

### What the path cannot establish

- The key does not show that Windows Setup ran or that an installation succeeded.
- A capacity or retention setting does not prove events were lost or a file reached its limit.

### Applicability

The referenced ADMX CSP tables list device scope on Pro, Enterprise, Education, and IoT Enterprise: Windows 10 2004/20H2/21H1 with KB5005101, and Windows 11 21H2 or later. These are CSP delivery baselines; they do not date the introduction of the underlying Group Policy setting.

### Selected values and subkeys

These are documented examples, not an exhaustive schema or observed data.

- **Enabled** (value): Controls whether the Setup channel accepts event writes.
- **Retention** (value): Controls retaining old Setup events when the log reaches maximum size.
