## Functional explanation

Status: **documented**

Role: merged&#95;class&#95;registration&#95;view

HKCR exposes a merged view of machine and current-user class registrations. The backing branches are HKLM&#92;Software&#92;Classes and HKCU&#92;Software&#92;Classes. File associations and COM metadata are interpreted through that view, whose result depends on user and process context. A record using HKCR must therefore preserve the originating security context and registry view before attributing the data to a machine-wide or per-user registration.
