## Functional explanation

Status: **documented**

Role: recurring&#95;per&#95;user&#95;logon&#95;command&#95;registration

Run is a documented location for registering commands that Windows schedules each time the represented user logs on. Named entries contain command lines, and multiple entries may be present without a guaranteed execution order. Windows can delay their launch to reduce interference with foreground work. The key describes logon configuration, so observing its contents is distinct from observing an attempted or successful program execution.

## Atomic claim

Registers commands to run on each logon for the user represented by HKCU.

Scope: **user**

## Meaning in system-level logs

For a write event, capture the value name, complete command line, prior data, writer identity, and result. Correlate later logon and process-creation records to determine whether that command actually executed.

### What the path cannot establish

- An entry does not prove that a logon occurred or that the program ran successfully.
- The location alone does not establish the command’s purpose, author, legitimacy, or maliciousness.

### Applicability

Documented Windows logon registry convention. Processing depends on the logon environment and applicable controls; the documentation says these keys are ignored in Safe Mode by default.
