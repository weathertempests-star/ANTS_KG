## Functional explanation

Status: **structural**

Role: machine&#95;locked&#95;down&#95;zone&#95;policy&#95;namespace

Lockdown&#95;Zones groups the numbered locked-down security-zone policy keys for the local machine. It parallels Zones without making the two branches interchangeable. Microsoft explains that Local Machine Zone Lockdown and Network Protocol Lockdown compare an active URL’s ordinary-zone settings with the locked-down equivalent. Documented children also hold OpenSearch action policies. The parent is a structural namespace and neither enables lockdown by itself nor guarantees that stored action policies are more restrictive.

## Atomic claim

Groups machine policy settings for the locked-down counterparts of URL security zones.

Scope: **machine**

## Meaning in system-level logs

Preserve Lockdown&#95;Zones in the logged path and collect the numeric child and action value. Identify the consuming feature and its lockdown context before treating these settings as the ones used for a particular URL.

### What the path cannot establish

- Parent-key presence does not enable a lockdown feature or show it was applied.
- The name does not guarantee stricter values than the ordinary Zones counterpart.

### Applicability

This namespace is established by documented Windows security-zone policies. Underlying feature support and policy precedence must be checked on the specific Windows baseline.
