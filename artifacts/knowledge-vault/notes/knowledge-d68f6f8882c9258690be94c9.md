## Functional explanation

Status: **documented**

Role: application&#95;event&#95;log&#95;policy

This machine EventLog Application policy key configures administrative aspects of the Application event log. Reviewed mappings include automatic backup when full, log access permissions, and the log file location. Automatic backup depends on retaining old events. This policy key is not the event file or an application activity record, and its modern access setting must be distinguished from the separately mapped legacy service setting.

## Atomic claim

Stores administrative policy for Application event-log file handling and access.

Scope: **machine**

## Meaning in system-level logs

A registry target here concerns Application log configuration. Inspect the exact value and data with operation and result; a backup or log-file access requires matching file or Event Log evidence rather than inference from the key.

### Applicability

The referenced ADMX CSP tables list device scope on Pro, Enterprise, Education, and IoT Enterprise: Windows 10 2004/20H2/21H1 with KB5005101, and Windows 11 21H2 or later. These are CSP delivery baselines; they do not date the introduction of the underlying Group Policy setting.
