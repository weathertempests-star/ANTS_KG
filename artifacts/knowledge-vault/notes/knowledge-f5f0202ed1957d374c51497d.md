## Functional explanation

Status: **documented**

Role: defender&#95;cloud&#95;engine&#95;policy

This machine Windows Defender MpEngine policy key stores the reviewed setting for Microsoft Defender Antivirus cloud protection level, which controls how aggressively suspicious files are scanned or blocked using cloud protection. Microsoft separates turning cloud protection on from choosing that level and notes that a default-level zero can be misread by Resultant Set of Policy. The key is configuration, not a detection or threat-verdict record.

## Atomic claim

Stores Microsoft Defender Antivirus policy selecting the cloud protection blocking level.

Scope: **machine**

## Meaning in system-level logs

Identify the actual engine policy value and data with operation and result. Verify effective Defender preferences before describing the configured level; a file verdict, cloud query, block, or remediation requires separate Defender evidence.

### What the path cannot establish

- The key does not establish cloud connectivity or successful cloud protection queries.
- A configured blocking level does not prove any file was detected, blocked, or remediated.
- The path alone cannot distinguish default-level configuration from the misleading disabled representation in some policy reports.

### Applicability

Applies to Microsoft Defender Antivirus cloud protection on supported Windows releases. Policy branding before Windows 10 2004 may say Windows Defender Antivirus; cloud protection activation, engine level, licensing-dependent features, and effective configuration are separate considerations.
