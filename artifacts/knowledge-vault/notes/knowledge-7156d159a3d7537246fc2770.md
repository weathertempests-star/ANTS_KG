## Functional explanation

Status: **structural**

Role: machine&#95;ordinary&#95;zone&#95;policy&#95;namespace

Zones groups the numbered ordinary URL security-zone policy keys for the local machine. Its documented children use IDs zero through four for Local Machine, Local Intranet, Trusted Sites, Internet, and Restricted Sites. Individual action values configure behavior within a zone; they are not the site-to-zone assignment list. This policy namespace must also remain distinct from its Lockdown&#95;Zones sibling, whose equivalent-zone settings serve separate lockdown contexts.

## Atomic claim

Groups machine policy action settings for the five ordinary URL security zones.

Scope: **machine**

## Meaning in system-level logs

Use the numeric child and action value to interpret logs under Zones. Determine a particular URL’s actual zone from mapping and consumer context instead of assuming the policy path identifies a visited site.

### What the path cannot establish

- The Zones parent does not identify an action policy or its enabled state.
- This branch is not proof of a website assignment, browser navigation, or successful security decision.

### Applicability

This namespace is established by documented Windows security-zone policies. Underlying feature support and policy precedence must be checked on the specific Windows baseline.
