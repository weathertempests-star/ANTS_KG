## Functional explanation

Status: **documented**

Role: custom&#95;removable&#95;storage&#95;write&#95;policy

This Deny&#95;Write node is a user policy key for denying write access to selected custom removable-storage classes. It must be distinguished from a same-named registry value: Microsoft maps a Deny&#95;Write policy-state value inside this key. A preserved Microsoft-authored ADMX template additionally places the class-selection list in its List child. The location describes policy configuration, not an observed storage operation or proof that enforcement is active.

## Atomic claim

Configures user write restrictions for custom removable-storage classes.

Scope: **user**

## Meaning in system-level logs

Capture the Deny&#95;Write value data and relevant class-list contents, not just the final key name. Match the policy to device-class and access-result records before deciding whether an actual write was denied.

- The key name is not evidence of an attempted or completed storage operation.

### Applicability

The cited user ADMX CSP mappings cover serviced Windows 10 baselines with KB5005101 and Windows 11 21H2 or later on the listed managed editions. Individual legacy-policy limitations still apply. List-child and numeric state details were additionally checked in the Microsoft-authored ADMX preserved in NSA’s historical baseline (revision 1.0, supportedOn WindowsVista); this does not prove a universal present-day schema.
