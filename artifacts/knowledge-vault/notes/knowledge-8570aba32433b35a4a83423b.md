## Functional explanation

Status: **structural**

Role: event&#95;log&#95;policy&#95;namespace

This machine EventLog policy namespace groups administrative controls for Application, Security, Setup, and System logging. Documented child policies configure file locations, access, retention, automatic backup, and selected channel settings. Its namespace role is inferred from these child mappings. It is separate from legacy service configuration under System CurrentControlSet Services EventLog, and from the event files that store actual records.

## Atomic claim

Groups machine administrative policies for Event Log channels.

Scope: **machine**

## Meaning in system-level logs

A registry target here concerns logging policy. Identify the channel child, value, data, operation, and result; event creation, deletion, clearing, or file rollover must be demonstrated by separate channel or file evidence.

### What the path cannot establish

- This registry namespace does not contain the actual event records.
- Its presence does not show a log was cleared, a record was written, or logging is disabled.
