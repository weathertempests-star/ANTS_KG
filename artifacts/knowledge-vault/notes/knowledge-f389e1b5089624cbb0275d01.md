## Functional explanation

Status: **structural**

Role: com&#95;class&#95;registration&#95;namespace

CLSID organizes machine COM registrations by class identifier. A child GUID names one class-registration record; the parent is a collection rather than a particular COM implementation. Server paths and other activation-related metadata belong beneath individual class entries. Keep the concrete class identifier when analyzing a record so that registrations for unrelated components are not collapsed into a single behavior.
