## Functional explanation

Status: **documented**

Role: event&#95;log&#95;service&#95;configuration

EventLog groups registry configuration for event logs and their resource registrations. Each log has a child record used by event logging facilities. This parent describes configuration, not the events stored in log files. It must remain distinct from Software&#92;Policies&#92;Microsoft&#92;Windows&#92;EventLog policy settings and from channel data. To interpret a registry record, identify the log child and exact setting before claiming an effect on logging.

## Atomic claim

EventLog groups registry configuration for event logs and their resource registrations.

Scope: **machine**

## Meaning in system-level logs

An EventLog registry event needs the log child and setting; it is not itself evidence that an event log was cleared.

### What the path cannot establish

- The registry tree does not contain the event records themselves.
- The parent does not establish that logging is disabled or that a log was cleared.

### Applicability

Classic Event Logging documentation distinguishes the redesigned Windows Event Log infrastructure introduced in Windows Vista.
